📊 Student Performance Analytics System

A Python-based Student Performance Analytics System that helps manage student records, analyze academic performance using statistical and probability concepts, demonstrate Object-Oriented Programming (OOP), and visualize student marks through different graphs.

🚀 Project Overview

The Student Performance Analytics System is a menu-driven Python application designed to manage student information and perform detailed academic analysis.

It allows users to add, update, delete, and display student records. It also calculates statistical measures, performs probability analysis, demonstrates OOP concepts, and generates graphical representations of student performance.

📈 Data Visualization

The project generates five different graphs to understand student performance.

Histogram – Shows the distribution of student marks.
Bar Chart – Compares marks of individual students.
Box Plot – Displays the distribution and spread of marks.
Scatter Plot – Shows marks against student numbers.
Line Chart – Displays student marks using a line graph.

All generated graphs are automatically saved in the screenshots/ folder.
